# BYLINE 위젯 프로토타입 — 버전 히스토리

## v1 — 최초 프로토타입
**시점:** "코드에 넣은 프롬프트 작성해줘" → "하자" (Figma 확인 전)

- 컨셉: Vol 카드형 아카이브 그리드 + 뉴스룸 스탬프 톤
- 세리프 마스트헤드("BYLINE"), 톤: Ink/Paper/Stamp Red(오브스톤) 팔레트
- 발행 버튼 클릭 → 오늘 날짜 저장, 도장 찍듯 "★ Published ★" 애니메이션
- 그리드: Vol 번호 + 날짜가 카드 안에 텍스트로 표시, 완료=채움/미완료=점선/오늘=빨간 테두리
- 저장: `window.storage` (Claude 아티팩트 전용)

## v2 — Figma 디자인 시스템 반영 리빌드
**시점:** "0. 피그마 연동 확인 후 디자인 반영" 외 3건

- Figma 파일(BYLINE Widget Design) 실제 확인 → 디자인 전면 교체
- Vol 카드형 그리드 → **요일 헤더(M T W T F S S) + 주간 캘린더 그리드**
- 세리프 → **Inter 계열 산세리프** (Figma 타이포 스펙)
- 컬러 팔레트: Ink `#1A1A1A` / Cream `#FAFAF8` / Stone(베이지) / Mist `#9E9E9E`
- 신규 기능 4종 추가:
  - 발행 취소 버튼
  - 2026.06.01~07.25 목업 데이터 (완료:미완료 = 7:3, 8주치)
  - 세로/가로 모드 토글
  - 라이트/다크 모드 토글

## v3 — 1주차 기획 재정렬 + 경고 장치
**시점:** "1. 1주차 기획안 반영하여 figma도 수정" 외 4건

- 1주차 원안 재확인 결과 반영: 미완료 셀 = **베이지 채움 → 점선 빈 칸**으로 정정 (Figma 파일도 동일하게 수정, node 13:11/13:13)
- **최근 발행일 공백 경고 장치** 추가: 3일 이상 미발행 시 "⚠ 최근 발행: ... · N일째 공백" 강조 표시 (새 색상 없이 굵기+아이콘만 사용)
- 코드 버전 관리 체계 도입 (원본 + 버전 파일 분리), `window.storage`가 프로토타입 임시 저장소임을 코드 주석으로 명시
- (참고) 이 시점에 GitHub 이슈 자동 등록을 시도했으나 쓰기 권한 없어 실패 → 이슈 초안만 텍스트로 제공

## v4 — 빈티지 신문 컨셉 전면 재설계 (현재 최신)
**시점:** "1. 다크에서 완료, 미완료가 구분이 잘 안가는데..." 외 4건

- **다크모드 대비 개선**: 완료=크림 솔리드 채움 / 미완료=옅은 크림 틴트+점선 테두리로 명확히 구분 (기존엔 미완료 테두리 색이 배경과 거의 같아 안 보였음)
- **가로모드 컨셉 유지**: 마스트헤드·이중 룰선은 항상 전체 폭 유지, 본문(그리드+오늘의 CTA)만 컬럼 분할 — 헤더가 잘려 컨셉이 깨지던 문제 해결
- **일/주/월 보기 모드** 추가: 월=실제 달력(6월↔7월 이동), 주=선택 주 7칸 스트립, 일=포커스 카드(←→ 날짜 이동)
- **날짜 클릭 → 상세 패널**: Vol 번호 확인 + "발행 취소/발행으로 표시" 토글, 과거 날짜도 수정 가능 (Vol 번호는 날짜순 실시간 재계산)
- **빈티지 신문 특색 추가**:
  - 세리프 마스트헤드 + "NO.0XX / 날짜" 데이트라인
  - 이중 룰선 (신문 헤더 하단 구분선)
  - 종이 비네트 효과 (box-shadow)
  - "오늘" 우표 스탬프 배지 (포인트 컬러는 이 한 곳에만 사용)
